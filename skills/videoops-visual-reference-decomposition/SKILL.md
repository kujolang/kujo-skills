# VideoOps visual reference decomposition

## Purpose

Use this skill for extracting reusable production principles from video references. Primary sources are supplied references and VideoOps motion/brand standards.

## Workflow

Record pacing, density, typography, framing, media mix, transition classes, and sound rhythm; separate general principles from distinctive expression; map only compatible principles to the style plan.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not reproduce a reference shot-for-shot or imitate a creator's distinctive work. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
