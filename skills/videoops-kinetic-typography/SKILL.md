# VideoOps kinetic typography

## Purpose

Use this skill for implementing readable motion typography in HyperFrames. Primary sources are typography standard, shot list, platform size, and approved font references.

## Workflow

Build clear hierarchy; animate scale, crop, position, appearance, and removal by meaning; sample critical frames; verify contrast, safe bounds, dwell time, and target-size readability.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not copy font binaries without rights or treat a webpage layout as video design. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
