# Integration / Partnership Launch

## Job to be done

Show why two systems are more useful together.

This is not a logo animation.

Good Kujo candidates:

- Kujo x Cloudflare
- Workcell x Daytona
- Kujo x Ollama
- Ability x MCP
- SearchBridge x a new data provider
- Kujo Pi x Pi
- GitHub / agent-harness integrations

## Core question

The video must answer:

**What can the viewer do now that they could not do, or could not do as cleanly, before this integration?**

If there is no good answer, the video should not exist yet.

## Story patterns

### A. Handoff
1. System A produces an artifact/state
2. integration boundary
3. System B consumes it
4. combined outcome

### B. One workflow, two capabilities
1. user request
2. Kujo handles orchestration/control
3. partner/provider handles specialized capability
4. output returns to Kujo
5. outcome

### C. Friction removed
1. manual bridge
2. integration reveal
3. direct connected workflow

## Branding rules

- both identities should be represented accurately
- Kujo styling remains the composition system
- partner colors/logos should not be distorted
- avoid implying formal partnership if the release is merely compatibility/integration
- wording must match the actual relationship

Use “integration with,” “support for,” “works with,” etc. unless partnership status is verified.

## Motion

Best visual motif: **handoff**.

Examples:

- data token crosses a boundary
- terminal command resolves into provider surface
- workflow node lights up
- artifact moves between systems
- one logo shape resolves into a shared workflow, not a logo mashup

## Product proof

At least one actual integrated workflow is required.

Examples:

- choose provider -> run task -> see output
- connect service -> fetch data -> use result
- launch Workcell on backend -> agent executes -> trace confirms

## Audio

Short and confident.

Often works without VO.

For longer versions, explain the combined workflow rather than describing each company.

## Acceptance criteria

- relationship wording is accurate
- both brands are visually accurate
- combined workflow appears on screen
- the integration boundary is understandable
- no logo-only opening >2s
- no fake partner quote
- no unsupported “official partnership” language
- CTA points to integration docs/install/example
