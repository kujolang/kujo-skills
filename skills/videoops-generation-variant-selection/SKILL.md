# VideoOps generation variant selection

## Purpose

Use this skill for selecting among materially different generated media variants. Primary sources are inspected variants, shot acceptance criteria, and brand rules.

## Workflow

Reject defective variants; compare only meaningful differences; choose the strongest compliant default; retain one fallback only when it changes a useful production choice; record rationale.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not create or retain near-duplicate variant spam. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
