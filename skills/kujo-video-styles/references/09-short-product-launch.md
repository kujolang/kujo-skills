# Short Real-Product Launch

## Job to be done

Explain a product in one pass using real product footage and a very small number of beats.

This is ideal for Kujo's individual tools:

- SearchBridge
- Eval
- ChangeBucket
- BluePencil
- Ability
- CaseFile
- Shipcheck
- Lens
- Docsgen
- etc.

It should be polished enough for a landing-page hero but short enough for social.

## Core rule

**One beat = one visual promise = one spoken or written idea.**

Do not narrate something unrelated to what the viewer is seeing.

## Default five-beat structure

For ~20 seconds:

1. **Hook** — 2–3s
2. **Primary workflow** — 4–5s
3. **Second capability** — 4–5s
4. **Outcome/proof** — 4–5s
5. **Identity/CTA** — 2–3s

Not every product needs exactly five beats. The point is discipline.

## Product capture

Use authentic product recordings whenever possible.

Capture requirements:

- clean deterministic demo data
- remove private information
- stable cursor movement
- no accidental notifications
- no irrelevant browser chrome unless useful
- crop to the meaningful region
- capture at sufficient resolution for zooming

Do not fake a product screen simply because it is faster.

## Narration

If used, narration should be concise enough that each sentence maps to a beat.

A 20-second film does not have room for a full product description.

Use:
- what it does
- one differentiator
- one outcome

Omit:
- company history
- exhaustive feature list
- generic adjectives

## Motion

Use motion to focus attention:

- zoom into the action
- spotlight relevant control
- move from input to output
- let real UI carry most of the film
- use type between product beats rather than over the critical UI

## Audio

- optional VO
- modest music bed
- 2–5 authored SFX total
- avoid trailer sound-design excess

## Acceptance criteria

- product is visible by ~3s
- every narrated sentence maps to the current visual
- 3–5 meaningful beats
- real app/product footage dominates
- one clear takeaway
- CTA <=3s
- no generic filler scene
- works on landing page and social crop where intended

## Reference study

Reset90 case study:
https://reset90ai.app/blog/build-product-launch-video-codex-hyperframes

The project describes a short deterministic HyperFrames film built from real app recordings, a reference film, and a compact beat structure. The important lesson is the disciplined alignment between each spoken idea and each visual beat.
