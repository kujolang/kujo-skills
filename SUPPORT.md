# Support

Use [GitHub Issues](https://github.com/kujolang/kujo-skills/issues) for reproducible problems with this skills pack, including stale commands, incorrect routing, missing source references, and validation failures.

Before opening an issue:

```bash
bash tests/release-readiness.sh
```

Include the skill name, commit, agent/runtime, expected behavior, actual behavior, and relevant non-sensitive output. Questions or bugs about the Kujo language/runtime should go to the main Kujo project rather than this distribution repository.
