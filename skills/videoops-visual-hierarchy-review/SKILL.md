# VideoOps visual hierarchy review

## Purpose

Use this skill for reviewing legibility, crop, clutter, focus, and text priority. Primary sources are rendered frames, target dimensions, typography and brand standards.

## Workflow

Inspect representative and transition frames; verify critical copy, focal priority, safe crop, contrast, and density; cite exact frames and affected claims; distinguish defect from preference.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not infer offscreen behavior without inspected evidence. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
