# VideoOps pacing analysis

## Purpose

Use this skill for finding dead space, unreadable micro-cuts, uniform rhythm, and weak semantic timing. Primary sources are render, shot boundaries, transcript beats, and motion standard.

## Workflow

Sample complete video and transitions; compare visual change to semantic/audio beats; identify stalls or overload with timestamps; propose measurable timing acceptance.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not fail solely because pacing differs from personal taste. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
