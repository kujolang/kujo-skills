# Security Policy

## Supported version

Security fixes are applied to the current `0.1.x` technical-preview line. Older snapshots and unmerged branches are not supported release baselines.

## Reporting a vulnerability

Use GitHub's private **Report a vulnerability** flow when it is available for this repository. If private reporting is unavailable, contact a repository maintainer through the Kujolang organization without including exploit details, credentials, or sensitive evidence in a public issue.

Include the affected skill or file, impact, reproduction conditions, and the smallest safe evidence bundle. Please allow maintainers time to confirm the report before public disclosure.

## Scope

This repository distributes instructions and metadata. It does not enforce agent behavior, sandbox Kujo programs, or provide a hosted execution service. Security reports about the Kujo runtime itself should be directed to the main Kujo repository.
