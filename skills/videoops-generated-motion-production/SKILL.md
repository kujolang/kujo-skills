# VideoOps generated motion production

## Purpose

Use this skill for creating a short purpose-built motion asset or loop. Primary sources are generation handoff, shot duration, adjacent motion, and approved provider.

## Workflow

Match exact edit duration and direction; generate minimal variants; inspect looping, artifacts, frame rate, crop, and codec; normalize and register the selected result.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not create long expensive generations for micro-inserts or unrelated filler. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
