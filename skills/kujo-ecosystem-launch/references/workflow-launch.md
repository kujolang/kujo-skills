# Workflow Launch Variant

- Verify every workflow kit, shared contract, catalog entry, fixture path, installer, and orchestration dependency.
- Prove isolated installation and the narrowest representative fixture before the composed lifecycle fixture.
- Verify pause/resume, idempotency, bounded retries, permission gates, no-network behavior, record ownership, checksums, receipts, and blocker states where applicable.
- Release the containing workflow repository only after catalog counts, version metadata, compatibility locks, docs, tests, and clean-checkout proof agree.
- Publish one site page per released workflow plus the updated workflow catalog and ecosystem counts.
- Use release-pinned setup commands that work from a fresh checkout; do not advertise sibling-checkout assumptions as installation instructions.
