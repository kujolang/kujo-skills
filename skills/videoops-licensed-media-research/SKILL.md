# VideoOps licensed media research

## Purpose

Use this skill for researching external media with documented reuse rights. Primary sources are asset requirement and licensing policy.

## Workflow

Search lawful public sources; retain source/creator/license/terms/retrieval evidence; distinguish discovery from production approval; download only an explicitly reusable candidate.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Public visibility or downloadability is never proof of reuse permission. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
