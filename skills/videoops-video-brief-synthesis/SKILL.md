# VideoOps video brief synthesis

## Purpose

Use this skill for turning validated VideoOps intake into a concise creative brief without inventing claims. Primary sources are PackWrite intake artifacts and VideoOps production standards.

## Workflow

Validate all intake; extract thesis, audience, promise, evidence, constraints, CTA, and non-goals; flag unsupported claims; write the creative brief.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not source media or decide implementation details owned by later roles. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
