# Webops Content Gap

## Purpose

Use this skill for classifying site coverage against audience/search needs. Its primary sources are ContentGraph corpus, research, optional query data, and current site profile.

## Workflow

1. Build a normalized set of audience/search needs with provenance.
2. Map each need to content nodes and evidence.
3. Classify covered well, partially covered, stale, weak, missing, or irrelevant.
4. Distinguish genuine audience value from competitor mimicry.

## Required Output

- coverage matrix.
- gap classifications.
- supporting nodes.
- evidence gaps.

Every output must name target/scope, evidence class, retrieval or run time,
unavailable checks, permission mode, and comparison baseline where applicable.

## Boundaries

A competitor page or keyword estimate alone does not establish a valuable content gap. Preserve OBSERVE/PROPOSE/ACT boundaries, provider cost and credential
limits, stable finding identity, and the distinction among finding,
recommendation, action, and outcome. Never store credentials or fabricate
provider data, rankings, indexing, citations, compliance, or causation.

## Verification

Validate source artifacts with their owning tool before interpretation. Run
the current repository's WebOps cross-reference validation when agent, skill,
tool, capability, or workflow mappings change.
