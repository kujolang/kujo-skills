# VideoOps motion quality review

## Purpose

Use this skill for reviewing transitions, easing, distortion, compositing, and effect use. Primary sources are render, motion standard, style plan, and sampled/key frames.

## Workflow

Inspect continuity, easing, jitter, unintended flashes, effect purpose, seam artifacts, and motion consistency; identify timestamped repairs with acceptance criteria.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not demand decorative motion or penalize intentional hard cuts. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
