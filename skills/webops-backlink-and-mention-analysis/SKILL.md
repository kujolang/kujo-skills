# Webops Backlink And Mention Analysis

## Purpose

Use this skill for analyzing new/lost backlinks, linked and unlinked mentions, and evidence-backed link concerns. Its primary sources are SearchBridge backlink data, public web research, and prior run.

## Workflow

1. Validate provider coverage, target, retrieval window, and cost boundary.
2. Compare stable link identities for new/lost state.
3. Research relevant mentions and distinguish linked/unlinked.
4. Label suspicious patterns cautiously and preserve provider/public-web limitations.

## Required Output

- new/lost links.
- mention inventory.
- unlinked candidates.
- evidence-backed risks.

Every output must name target/scope, evidence class, retrieval or run time,
unavailable checks, permission mode, and comparison baseline where applicable.

## Boundaries

Without a provider, do not claim complete backlink change coverage or create disavow actions. Preserve OBSERVE/PROPOSE/ACT boundaries, provider cost and credential
limits, stable finding identity, and the distinction among finding,
recommendation, action, and outcome. Never store credentials or fabricate
provider data, rankings, indexing, citations, compliance, or causation.

## Verification

Validate source artifacts with their owning tool before interpretation. Run
the current repository's WebOps cross-reference validation when agent, skill,
tool, capability, or workflow mappings change.
