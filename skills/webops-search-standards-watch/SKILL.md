# Webops Search Standards Watch

## Purpose

Use this skill for monitoring authoritative search, indexing, structured-data, analytics, browser, AI-search, and web-standard changes. Its primary sources are Official search-engine, analytics, browser, standards-body, and provider documentation.

## Workflow

1. Use primary authoritative sources and record publication/retrieval dates.
2. Distinguish final guidance, deprecation, experiment, draft standard, and rumor.
3. Assess applicability against the site profile and current implementation.
4. Create a bounded watch finding only when action or monitoring is warranted.

## Required Output

- standards change record.
- authority/status.
- site applicability.
- recommended follow-up.

Every output must name target/scope, evidence class, retrieval or run time,
unavailable checks, permission mode, and comparison baseline where applicable.

## Boundaries

Do not amplify SEO rumor or treat draft guidance as settled. Preserve OBSERVE/PROPOSE/ACT boundaries, provider cost and credential
limits, stable finding identity, and the distinction among finding,
recommendation, action, and outcome. Never store credentials or fabricate
provider data, rankings, indexing, citations, compliance, or causation.

## Verification

Validate source artifacts with their owning tool before interpretation. Run
the current repository's WebOps cross-reference validation when agent, skill,
tool, capability, or workflow mappings change.
