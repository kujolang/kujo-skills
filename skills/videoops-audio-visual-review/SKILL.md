# VideoOps audio visual review

## Purpose

Use this skill for checking speech clarity, synchronization, impact timing, music, and silence. Primary sources are rendered audio/video streams, transcript, planned beats, and audio standard.

## Workflow

Probe streams; listen/inspect complete output; check sync, clipping, dropouts, speech masking, transitions, and intended silence; cite timestamped evidence.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not claim loudness or sync facts without tool/listening evidence. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
