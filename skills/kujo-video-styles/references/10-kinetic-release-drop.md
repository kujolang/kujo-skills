# Kinetic Release Drop

## Job to be done

Create the smallest useful Kujo release video.

This format is for **attention**, not explanation.

Use when:

- version just shipped
- a feature name is strong enough to stand alone
- you need a teaser before a longer launch
- the release has one visually satisfying artifact
- you want a high-frequency social post

Examples:

- `ABILITY 0.3`
- `WORKCELL: CLOUDFLARE`
- `SEARCHBRIDGE + DATAFORSEO`
- `KUJO 0.X`
- a benchmark record
- a new provider

## Core rule

One line. One visual mechanism. One reveal.

Usually no voiceover.

## Structure

### Option A — Name-first
1. product/version
2. kinetic transformation
3. proof glimpse
4. URL/logo

### Option B — Proof-first
1. terminal/UI moment
2. result
3. feature/version name
4. Kujo

### Option C — Metric-first
Only when measured:
1. number/stat
2. context
3. release
4. CTA

## Visual language

This is where stronger graphic experimentation is allowed:

- kinetic type
- rulers/grids
- crop/mask
- typographic distortion
- subtle chromatic treatment
- texture/noise
- scanline/terminal motifs
- fast scale changes
- hard cuts
- synchronized graphic SFX

But choose **one** primary visual idea.

Do not turn 8 seconds into a demo reel of animation techniques.

## Copy limits

Recommended:

- hero: 1–6 words
- support: <=10 words
- CTA: URL or command only

No paragraphs.

## Audio

- no VO by default
- one music cue or tonal bed
- 1–4 sharp SFX
- cut motion to audio deliberately

The video should remain effective muted.

## Loopability

Where the destination supports autoplay looping:

- design first and final frame to relate
- avoid a dead 1-second end card
- optionally make the last motion feed back into the opening

## Implementation primitives

- kinetic wordmark
- version counter
- ruler/grid
- terminal flash
- metric count-up
- mask slam
- logo sting
- chromatic micro-offset
- texture overlay
- seamless loop helper

Effects must be configurable and brand-safe.

## Acceptance criteria

- <=12s unless deliberately overridden
- <=1 core message
- <=1 dominant visual motif
- no voiceover unless explicitly justified
- message readable on first watch
- payoff within 5s
- works muted
- clean final/loop state
- real metric only if sourced
