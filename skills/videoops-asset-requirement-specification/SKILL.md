# VideoOps asset requirement specification

## Purpose

Use this skill for translating approved shots into precise asset requirements. Primary sources are shot list, transcript, creative brief, asset and license policy.

## Workflow

Assign stable requirement IDs; describe source priority, crop, duration, resolution, alpha/audio needs, authenticity, shot mapping, and acceptance; mark required versus optional.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not source, capture, or generate the asset. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
