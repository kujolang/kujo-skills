# VideoOps shot planning

## Purpose

Use this skill for creating frame/time-bound VideoOps shot plans. Primary sources are creative brief, transcript, platform JSON, motion standard, and shot-list schema.

## Workflow

Calculate the complete timeline; define every shot's start, end, duration, purpose, visual, copy/audio, assets, motion, transitions, and priority; validate continuity and schema.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not leave timeline gaps or delegate core creative decisions downstream. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
