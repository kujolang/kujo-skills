# VideoOps hyperframes project bootstrap

## Purpose

Use this skill for creating a composition with current HyperFrames conventions. Primary sources are approved planning package, platform JSON, manifest, and installed HyperFrames CLI.

## Workflow

Run version/doctor; scaffold or create the bounded project; set deterministic composition metadata; wire only approved assets; record CLI version and commands; run initial lint/check.

## Required Output

Write only the role-owned, workspace-relative artifacts named by the current VideoOps agent contract. Include evidence, unavailable capabilities, attempt number, model profile, validation outcome, and an explicit handoff or blocker.

## Boundaries

Do not assume deprecated HyperFrames APIs or hide missing assets. Preserve role ownership, rights, credentials, provider-cost approval, and the distinction between deterministic facts and model judgment.

## Verification

Validate required inputs before work and outputs afterward. Run deterministic checks before semantic evaluation. Use at most two economical attempts, record stage-local escalation, and never accept a failed artifact because of cost pressure.
